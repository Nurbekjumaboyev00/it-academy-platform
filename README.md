# IT Online Academy Platform

## Project Description
The IT Online Academy Platform is an educational platform designed to provide online courses and resources for students and professionals in the IT field. It offers a variety of learning materials, interactive quizzes, and a community forum to enhance the learning experience.

## Features
- Comprehensive course catalog covering various IT topics
- Interactive quizzes for self-assessment
- User-friendly interface for easy navigation
- Community forum for discussions and support
- Admin panel for managing courses and users

## Telegram Setup
To set up Telegram notifications:
1. Create a bot using [BotFather](https://core.telegram.org/bots#botfather) and get the API token.
2. Configure the bot's webhook URL to point to your server.
3. Implement the required code to send notifications via the bot.

## Installation Instructions
1. Clone this repository:
   ```bash
   git clone https://github.com/Nurbekjumaboyev00/it-academy-platform.git
   ```
2. Navigate to the project directory:
   ```bash
   cd it-academy-platform
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Set up your environment variables as required.
5. Run the application:
   ```bash
   npm start
   ```
6. Access the application in your web browser at `http://localhost:3000`.
